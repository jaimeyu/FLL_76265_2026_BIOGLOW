# Ideas & Brainstorming (`doc/ideas/`)

Notes, sketches, research topics, and creative concepts for both the Innovation Project and Robot Design.

## Guidelines
- No idea is a bad idea during initial brainstorming!
- Document the problem statement, proposed solution, and feasibility.
- Include feedback from experts, coaches, or community members when evaluating ideas.

## 🛠️ Design & Brainstorming Tools
- **[Printable Robot Design & Mission Sketchpad](../marketing/handouts/mission_design_sketchpad.html)**: Ready-to-print engineering idea sheet for kids with Mission #, Design #, summary area, student name, drafting grid with LEGO Technic beam scale, and peer "Plus'ing" feedback.
