# Presentations & Judging Materials (`doc/presentations/`)

Scripts, slide decks, outline notes, and Q&A prep for official FIRST LEGO League judging sessions.

## Judging Categories
1. **Innovation Project Presentation**: 5-minute presentation + 5-minute Q&A.
2. **Robot Design Judging**: Explanation of robot chassis, attachments, code strategy, and field runs.
3. **Core Values Judging**: Shared story of teamwork, inclusion, and gracious professionalism throughout the season.
