# Mission Notes & Analysis (`doc/notes/missions/`)

Documentation, breakdown notes, field strategy maps, and risk/reward analyses for BIOGLOW table missions.

## Mission Note Template
When documenting a mission, include:
1. **Mission Name & Number**
2. **Point Value & Max Potential Points**
3. **Location on Mat** (Home launch area distance/angle)
4. **Required Attachment Mechanism** (e.g. passive hook, active motorized arm)
5. **Strategy & Sequence** (Combined with which other missions in a single run)
6. **Risk Factor** (Low / Medium / High) & Reliability percentage.
