# Engineering Journal & Meetup Notes (`doc/journal/`)

Meeting notes, build logs, code testing iteration records, and team decisions from every workshop.

## Log Entry Structure
For each meeting log (e.g., `2026-09-06-meetup.md`):
1. **Date & Location**
2. **Attendees** (First names or roles only)
3. **Goals for Today**
4. **Work Accomplished** (Hardware updates, software code changes, project research)
5. **Testing Results & Failures Learned From**
6. **Action Items & Next Steps**
