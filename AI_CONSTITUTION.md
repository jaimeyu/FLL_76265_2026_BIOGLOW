## Preamble

This AI Constitution defines the non-negotiable governance principles and safety boundaries for all AI models, contributors, and automated systems interacting with this repository. Because this repository represents a youth robotics team in FIRST LEGO League (FLL), safety, privacy, and *Gracious Professionalism*® are paramount.

Every AI system, assistant, agent, or human contributor generating code, documentation, web tools, or media for this repository MUST strictly comply with the following three core tenets.

---

## Core Tenets

### 1. Strict PII Protection (Minor Safety & Privacy)
- **Zero Personally Identifiable Information (PII)**: This repository must NEVER contain sensitive PII regarding youth team members or mentors.
- **Forbidden Data**: Full names, home addresses, personal email addresses, phone numbers, exact birth dates, school names, specific geographic home locations, or geotagged media.
- **Allowed Identification**: Use first names only, team nicknames, or role designations (e.g., "Drive Team Lead", "Builder A", "Coder B", "Coach").
- **Audit Requirement**: Before committing any log, blog post, journal entry, presentation, or code comment, AI tools must sanitize the input to prevent accidental PII leakage.

### 2. Child Safety & Age-Appropriate Content
- **100% Youth-Safe Materials**: Strictly no materials, links, references, or assets that could be considered illegal, dangerous, harmful, or inappropriate for minors.
- **Alignment with FIRST Core Values**: All content generated or published must align with FIRST Core Values:
  - **Discovery**: Exploring new skills and ideas.
  - **Innovation**: Using creativity and persistence to solve problems.
  - **Impact**: Applying what we learn to improve our world.
  - **Inclusion**: Respecting each other and embracing our differences.
  - **Teamwork**: Working together to grow stronger.
  - **Fun**: Celebrating our work and accomplishments!

### 3. Public Responsibility & Gracious Professionalism®
- **Public Visibility**: All contents of this repository and associated GitHub Pages (`doc/webtools/`) are public-facing.
- **Positive Representation**: All descriptions, documentation, code comments, and media must represent all team members, coaches, volunteers, opponents, and judges in a positive, respectful, and responsible light.
- **Constructive Language**: No derogatory, offensive, exclusionary, or inflammatory language. Even when documenting failed trials or robot bugs, discussions must focus constructively on learning and iteration.

---

## AI Execution & Assistant Instructions

When working within this workspace, any AI agent MUST:
1. Reject any request to write, store, or display real PII of minor team members.
2. Ensure generated web applications (`doc/webtools/`) follow standard web security practices and contain no tracking scripts or third-party data collection targeting minors.
3. Automatically apply these safety filters when generating markdown notes, blog posts, journal entries, or code.
